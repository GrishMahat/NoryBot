# NoryBot Features

This section provides detailed documentation for all features available in NoryBot.

## 🎯 Core Features

- **Image Generation** - Create dynamic images and quotes
- **Ticket System** - Manage support tickets and user inquiries
- **Admin Commands** - Server management and moderation tools
- **MongoDB Integration** - Persistent data storage and configuration

## 🔒 Permission Requirements

Different features require different permission levels:
- Admin commands require administrator permissions
- Ticket system requires manage channels permission
- Image generation available to all users
- Data management restricted to bot owners
